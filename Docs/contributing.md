# Contributing

1. StudentHub da la bienvenida a las contribuciones de la comunidad para mejorar la plataforma.  
2. Crea una rama independiente desde main con un nombre claro para desarrollar tus cambios. 
3. Documenta o programa los ajustes necesarios manteniendo siempre el estándar del proyecto.  
4. Sube tu rama al repositorio remoto utilizando el comando git push.  Abre un Pull Request en GitHub para que el equipo revise y apruebe la integración a main.
