# Reglas del Equipo

* **Ramas:** No trabajar directo en `main`. Usar ramas descriptivas (ej. `docs/add-team-rules`).
* **Commits:** Hacer commits pequeños con mensajes claros.
* **Pull Requests:** Todo cambio a `main` debe pasar por un PR y ser revisado por un compañero.
* **Sincronización:** Hacer `git pull origin main` seguido para evitar conflictos.
